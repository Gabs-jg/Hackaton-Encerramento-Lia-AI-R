- Dataset: `datasets/golden-v0.3.json`, revisão interna 0.3.1.
- `dataset_sha256` e `golden_sha256` iguais aos das runs 01 e 02. Os hashes dos 16 arquivos do coletor também são iguais aos registrados na run 02.
- Commit registrado: `3317147cf7bdb73bdc5c2b67a2338070ecbbcb89`. Entre o commit das runs 01 e 02 (`d87a92a`) e este, não houve alteração em `tests/automacao`, no golden nem nas dependências.

- Modo API, versão solicitada `original`, sem `prompt_sistema`. A API não retornou confirmação da versão. Fase da base `nao_confirmada`; a data de referência não foi aplicada ao agente.
- 48 sessões novas, uma por caso, preservadas entre os turnos. As 86 respostas têm HTTP 200; isso comprova a coleta, não a correção funcional.
- Coleta de 01:07 a 01:11 UTC de 19/10/2026, sequencial, sem nova tentativa.
- Juiz: `us.anthropic.claude-sonnet-4-6`, região `us-east-2`, mesma configuração das runs 01 e 02. No bloco do juiz, mudam apenas `lote_id` (`t19-original-run03`) e o arquivo local de orçamento, da conta de outro integrante.
